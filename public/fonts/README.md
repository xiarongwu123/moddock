# Bundled title font

Fusion Pixel Font, 12px proportional Simplified Chinese, release 2026.09.25.

Source: https://github.com/TakWolf/fusion-pixel-font/releases/tag/2026.09.25

Archive: `fusion-pixel-font-12px-proportional-otf.woff2-v2026.09.25.zip`

The font file is unchanged from the release archive. Its filename omits `.otf` for the local URL. The release's `OFL.txt` and source-font notices are preserved in `fusion-pixel-licenses/`.

The login and registration titles use the font at 24px, twice the native pixel size. The rest of the interface retains its existing font.
