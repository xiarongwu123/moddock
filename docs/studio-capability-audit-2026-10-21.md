# Mod 制作适配核对（2026-10-21）

本表核对代码中的制作配方、构建和安装路线，不表示已在所有游戏版本中实测。游戏专项资料来自 `studio-skills.cjs`，可执行制作配方来自 `studio-recipes.cjs`；两者不是同一份支持名单。

## 本次新增

赛博朋克 2077：`cyberpunk-cet-lua`。支持单文件 CET Lua 玩法脚本、Lua 5.1 静态语法解析、ZIP 打包、标准目录安装、启用/禁用/卸载、独立 Mod 日志及功能回读验收。服务端 plan/generate/repair 和隔离源码工作区同步支持该类型。CET 缺失时可制作和导出，安装会阻止并说明依赖。

此路线不制作新模型、贴图、配音、任务资源、`.archive`、REDmod、redscript 或 RED4ext 原生插件；这些仍需各自工具链。现成 `.archive` 包安装不等于具备 `.archive` 制作能力。安装前需准备匹配游戏版本的 CET；本次没有加入未经版本匹配验证的 CET 自动下载安装。

## 有通用引擎路线、尚无该游戏专用适配

都市：天际线 2（949230）有专项资料；识别出 Unity Mono/IL2CPP 后可使用通用 Unity 制作路线。游戏 API、加载方式、版本兼容性和实际效果仍需针对该游戏验证，因此不能列为专用适配完成。

通用引擎路线还覆盖已识别的 Unreal、Unity、Godot、RPG Maker、Ren'Py 和 GameMaker。支持按本机证据调查与构建，不表示任意想法、任意版本都能完成。反作弊/联网保护、缺少代码或加载入口、工具不匹配等仍可能阻止交付。

## 其他常见缺口

- 上古卷轴 / 辐射系列目前没有 ESP/ESM、Papyrus、SKSE/F4SE 专用制作链；现成 Mod 的安装能力不能算制作适配。
- 星露谷物语已有 Content Patcher 对话/贴图配方，尚不等于通用 SMAPI C# 玩法插件制作。
- 博德之门 3 已有 Lua/人物跟随者与 PAK 路线，新增模型、配音、完整任务或剧情同伴仍不在该路线范围。
- 赛博朋克本次新增 CET 脚本路线；其他资产和框架仍按上文标记为缺口。

本地测试与真实游戏运行是两层证据。部署记录和测试报告见同批交付目录；本次未改动真实游戏或服务器。
