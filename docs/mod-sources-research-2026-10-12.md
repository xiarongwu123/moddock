# MOD 来源与游戏分类调研

调研日期：2026-10-12。面向 PC 游戏，以作者发布页、平台游戏专区和官方项目仓库为获取入口。

本次核对了资源页面、内容描述及部分安装说明，没有下载 MOD 文件或验证游戏内效果。页面存在不等于当前游戏版本可安装；未确认的下载、兼容性及付费状态保持待核对。

## 分类规则

| 一级分类 | 二级内容分类 | 判断依据 |
| --- | --- | --- |
| 游戏 MOD | 玩法与战斗 | 修改机制、敌人、难度、经济或成长 |
| 游戏 MOD | 剧情与任务 | 增加任务、对话、剧情或地区 |
| 游戏 MOD | 角色与外观 | 新增同伴、服装、皮肤、角色替换 |
| 游戏 MOD | 地图与建造 | 增加地图、建筑、家具或生产体系 |
| 游戏 MOD | 联机扩展 | 扩大人数或改变联机流程 |
| 游戏 MOD | 界面与便利 | 背包、地图、HUD、操作便利 |
| 画质增强 MOD | 高清贴图与模型 | 提升原有资产清晰度、几何细节和材质 |
| 画质增强 MOD | 光照与环境 | 改变天气、阴影、水体、植被、光照 |
| 画质增强 MOD | 调色与后处理 | ReShade 预设、色调、锐化、景深等 |
| 画质增强 MOD | 渲染增强 | 着色器包及其他渲染效果 |
| 辅助工具标签 | 性能与超分、帧生成 | 与画质相关，但不能默认宣传为画质提升 |
| 辅助工具标签 | 加载器与前置 | 用于运行 MOD，不作为内容 MOD 推荐 |

一个 MOD 可有多个内容标签。主分类依据主要作用：更换角色造型归角色外观；提升同一角色模型细节归画质。DaisyNiko 调色属于风格美化，不代表分辨率提高。新增地图伴随新贴图的综合扩展，主分类仍为游戏内容。

## MODDOCK 目录建议

展示层采用“游戏 → 游戏 MOD / 画质增强 MOD → 内容标签”。辅助工具通过标签和依赖关系关联到内容，避免把加载器当成玩法扩展。

每项资源建议保存：游戏标识与版本范围、主分类、内容标签、作者、原始来源、作者页面、下载文件标识、前置、安装类型、更新日期、价格状态、兼容性验证状态。

分类优先采用作者页面和平台分类，综合判断描述。关键词判断只能作候选；不能仅凭 textures、visual、performance 等单词自动归类，因为角色替换、便利工具和优化工具也可能含这些词。

当前项目 `sources.cjs` 声明了 Nexus、GameBanana、Steam 三个来源；Thunderstore、Modrinth、CurseForge 等只是本轮新增的调研来源，还未接入。Nexus 归一化目前把分类写成 `Mod`，如果后续实现内容筛选，需要保留来源分类后再映射；本次没有修改应用代码。

首批内容建议优先覆盖：星露谷、赛博朋克、上古卷轴 SE、辐射 4、巫师 3、艾尔登法环、博德之门 3；补充 Thunderstore 的致命公司/英灵神殿与 Minecraft 专门平台。

资源目录保存原始获取入口。下载、转载、镜像是不同授权范围；例如 HD Reworked Project 和多项 Nexus 作品的作者页禁止重新上传，目录收录不能默认转为 MODDOCK 自建文件镜像。
